# wsg

> **Archived:** `wsg` is no longer maintained.

`wsg` was a workspace manager for [Jujutsu](https://jj-vcs.github.io/jj/) repositories, with support for managing workspaces and running coding agents in parallel.

The project has been migrated and rewritten in Rust as [`jjfx`](https://github.com/Jarvvski/jjfx). Keeping this functionality alongside the project where I run and manage my own manual workspaces makes it easier to develop, use, and maintain than having it in a separate Go repository.

For the current implementation, installation instructions, usage, and future development, see [`Jarvvski/jjfx`](https://github.com/Jarvvski/jjfx).
